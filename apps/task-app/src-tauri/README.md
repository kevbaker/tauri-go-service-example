# Tauri Rust Project

This is the root of the standard Cargo project used by Tauri. It contains `Cargo.toml`, `build.rs`, `tauri.conf.json`, Rust source, capabilities, and generated icons. `Cargo.lock` is created and committed when Cargo first resolves the project.

Keep Rust limited to Tauri setup, bridge validation, authenticated proxying, and Go sidecar lifecycle. The generated greeting command is temporary scaffold code. See the repository's [Tauri patterns](../../../.agents/patterns/tauri.md).
