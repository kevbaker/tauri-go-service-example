# Project Guidance

This directory holds durable project guidance that supplements the root `AGENTS.md`.

## Directories

- `patterns/` documents repeatable implementation approaches that the codebase has adopted.
- `specs/` defines intended behavior and acceptance criteria before or alongside implementation.
- `decisions/` records consequential architecture choices and their tradeoffs.

Keep documents short, evidence-based, and close to the code they govern. Use lowercase kebab-case filenames. Prefer updating an existing document over creating overlapping guidance.

Planned behavior must remain distinguishable from implemented and verified behavior.
