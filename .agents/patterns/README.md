# Patterns

Store accepted, reusable implementation patterns here.

A pattern should state:

- the problem it addresses;
- the contexts where it applies;
- the preferred implementation shape;
- known exceptions or tradeoffs;
- links to representative code once it exists.

Current patterns:

- [Go services](go-services.md)
- [TypeScript and React](typescript-react.md)
- [Tauri applications](tauri.md)

The accepted bridge architecture is documented separately in [ADR 0001](../decisions/0001-electron-style-service-bridge.md) and the [service bridge POC specification](../specs/service-bridge-poc.md).
